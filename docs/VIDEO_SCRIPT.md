# 3 分钟演示视频脚本

> 目标时长 **2:50**（硬上限 3:00）。1920×1080，30fps，浏览器 100% 缩放，隐藏书签栏。
> 使用虚构演示数据；片尾固定免责声明。

---

## 一、录制前准备（10 分钟）

```bash
npm run start:easy
# 设置 → 刷新真实行情与宏观（预热）
# 配置分析 → 运行一次
# 智能决策 → 运行一次（生成 PDF）
```

预开标签页：

1. `/` 落地页
2. `/console` 总览
3. `/console/portfolio` 持仓与目标
4. `/console/analysis` 配置分析
5. `/console/agent` 智能决策
6. `/console/reports` 研报与记录

关闭通知；录音试 10 秒；语速约 260 字/分钟。

## 三、录制注意

- 每段先录 2 秒静止画面再操作，方便剪辑。
- 鼠标移动慢，点击前停顿 0.5 秒。
- 不要录终端报错、浏览器书签、真实姓名/账号。
- 片尾加 3 秒免责声明静态页。
- 导出 MP4（H.264），上传 B 站后填提交系统。
