## 八、版式与导出

### 海报

- 尺寸：A3 竖版 297×420mm，300dpi
- 安全边距：四周 ≥10mm
- 主色：深墨蓝 `#0a1220` + 品牌绿 `#12b886`
- 字体：思源黑体 / 阿里巴巴普惠体 / 微软雅黑
- 导出：PNG 300dpi；如要求 CMYK 再转

### PPT 封面 / 视频封面

- 1920×1080，16:9
- 标题字号 ≥ 72pt（视频封面可更大）
- 手机预览：3 秒能读出主标题
- 导出：PNG

### 海报信息层级

```text
作品名（最大）
一句话主张（第二）
定位说明
产品截图 / 辅助图形
三个能力点
关键数字
合规标识
团队信息（最小）
```

### 截图要求

- 浏览器 100% 缩放
- 去掉地址栏、书签栏
- 不出现真实姓名、Key、账号
- 优先：配置分析页 / Agent 轨迹 / 总览页

---

## 九、注意事项

1. 即梦生成后先检查有没有乱码文字；有就重生成或用消除笔擦掉。
2. 不要用 AI 生成真实图表、收益数字、K 线；一律用产品截图。
3. 不要用“金币、美元符号、牛、暴涨 K 线”等俗套元素。
4. 海报、PPT、视频封面尽量共用同一套颜色、字体、图形语言。
5. 合规声明必须保留，不要被裁切。
