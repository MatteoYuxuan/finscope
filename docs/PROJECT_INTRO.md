## 三、GitHub 仓库简介（约 250–300 字）

知衡 FinScope 是一个真实数据驱动的个人资产配置智能体，面向个人理财学习者、家庭资产管理人与小微企业主。

它解决三个断点：资讯与自身资产无关、知道要分散但不知道比例与载体、AI 建议像黑箱无法核对。系统接入 23 只核心 ETF 的复权日行情、中国宏观/利率/汇率与公开 RSS，结合用户持仓、负债、收入、目标与风险画像，通过风险平价、均值方差、Black-Litterman 三套战略引擎，叠加动量/趋势战术倾斜与约束投影，输出大类资产与 ETF 目标权重、再平衡清单、VaR/CVaR、压力测试、六套策略回测与教育金/养老/负债规划。

多智能体采用「规划—数据—宏观—组合—风险—目标—组合经理—审查员」分工：数字由 Python 量化引擎计算，LLM 只做解释，审查员检查个股推荐、目标价、收益承诺与数字一致性。系统支持 HTML/PDF 研报、交互图表与图像输入；无 LLM Key 时自动切换确定性智能体。建议边界为资产大类、策略与 ETF/基金筛选，不推荐个股，不承诺收益。

## 四、详细版（约 700–800 字，可用于 README/答辩材料）

**知衡 FinScope** 是一个面向个人与家庭的资产配置智能体，目标是把“看不懂的市场信息”和“说不清的资产结构”接到同一套可执行、可解释、可审计的决策链上。

传统工具通常只做资讯聚合，或只做记账，中间缺少一层：这些信息到底和我的钱有什么关系？我的资产比例是否合理？如果调整，具体调到多少、落到哪只 ETF、风险有多大？FinScope 试图回答这些问题。

系统有两个输入：一是公开市场数据，包括 23 只核心 ETF 的前复权日行情、中国 CPI/PPI/PMI/M2/GDP/LPR、中国与美国国债收益率、VIX、美元兑人民币，以及美联储/WSJ 等公开 RSS；二是用户自己的持仓、现金、负债、收入、风险画像与目标。数据全部缓存到本机 SQLite，断网时可用缓存演示，缺失数据显式标注，不用常识补数字。

量化层由三套战略引擎组成：风险平价让每类资产的风险贡献接近；均值方差在协方差约束下最大化夏普；Black-Litterman 把市场均衡收益与动量观点结合，并给观点设置置信度。三套权重按市场状态动态混合，再叠加 12-1 动量、200 日均线趋势与波动率的战术倾斜，最后通过 SLSQP 投影到单只 ETF、权益、海外、卫星、现金与换手上限的可行域。系统同时计算历史/参数 VaR、CVaR、最大回撤、相关性、风险预算，并用 2015 去杠杆、2018 贸易摩擦、2020 新冠、2022 全球加息等历史窗口与假设冲击做压力测试；回测覆盖等权、60/40、风险平价、MVO、BL 与集成策略，月度再平衡、单边 10bp 成本、无未来函数。

Agent 层采用多角色协作：Planner 拆解任务，Data & Quant 调用真实数据与量化引擎，Macro/Portfolio/Risk/Goal 四位专家分别解读，Portfolio Manager 综合，Risk Critic 检查是否出现个股推荐、目标价、收益承诺、权重合计异常或数字冲突。LLM 只读取结构化结果并写解释，不计算数字、不改目标权重；没有 LLM Key 时自动切换规则智能体，仍能完整运行。

输出层提供交互图表、配置对比、有效前沿、回测净值、回撤、压力测试、风险预算、相关性热力图、目标规划表，以及 HTML/PDF 研报。用户可以在「配置分析」查看量化结果，在「智能决策」查看多智能体轨迹并下载研报，在「研报与记录」回看历史。

产品边界明确：给资产大类、策略权重、ETF/基金筛选与再平衡步骤；不推荐个股，不给目标价、止损位或买卖点，不承诺收益。所有回测、VaR 与压力测试都基于历史样本与假设，不代表未来。

## 七、技术栈

- 前端：Next.js 15、React 19、Tailwind CSS 4、Recharts
- 后端：FastAPI、Pydantic、Python 3.13
- 量化：pandas、numpy、scipy（SLSQP、Ledoit-Wolf 收缩、VaR/CVaR、回测）
- 数据：AkShare / 东方财富、FRED、公开 RSS
- 存储：Prisma 6 + SQLite（用户数据）、SQLite（行情/宏观/运行/报告缓存）
- 报告：matplotlib + ReportLab（中文 PDF）
- 测试：Vitest（140 条）、pytest（6 条）、TypeScript 类型检查、Next build

## 八、适用场景

- 个人理财学习者：把资讯、资产与目标放到一张表里理解。
- 家庭资产管理人：检查集中度、流动性、期限、负债与目标缺口。
- 小微企业主：区分经营/家庭资产，做保守的流动性规划。
- 理财教育/投顾辅助：作为可解释、可审计的分析层，而非直接下单工具。
