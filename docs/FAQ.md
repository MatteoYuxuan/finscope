# 常见问题

## 一、运行与数据

### Q1. 没有 LLM Key 能跑吗？

能。系统会进入「规则智能体」：仍然拉真实 ETF 行情、跑风险平价/MVO/BL、回测、VaR、目标规划，并生成 HTML/PDF 报告；只是解读文字由确定性模板生成。页面会标注模式。

### Q2. 需要登录吗？

不需要。单机本地工具，打开工作台即可使用；数据保存在本机 SQLite。

### Q3. 数据会上传到哪？

默认不离开本机。只有配置并启用 LLM/视觉模型时，才会把**必要的结构化片段或图片**发给所配置的模型服务。Key 保存在 `services/quant/data/llm.json`，不写日志。

### Q4. 行情和宏观是真的吗？

ETF 日行情来自 AkShare/东方财富前复权数据；宏观来自统计局/央行/FRED；每个指标标注观测日期。演示持仓是虚构的，避免隐私。数据缺失会显式标注，不会用常识补数字。

### Q5. 怎么清空或恢复数据？

- 「设置 → 数据缓存」可刷新行情；
- `npm run db:reset` 清空并重建演示持仓/目标；
- 删除 `services/quant/data/market.db` 可清空行情与报告缓存。

### Q6. 量化服务离线怎么办？

```bash
npm run quant:dev
# 或
node scripts/start.mjs --check
```

确认 `http://127.0.0.1:8000/health` 返回 `ok`。如果 8000 被占用，用 `--quant-port 8001` 并同步 `QUANT_SERVICE_URL`。

### Q7. `npm install` 或 Prisma 报错？

先确认 Node 版本 ≥20.11；受限环境可尝试：

```bash
npm install --ignore-scripts
node node_modules/prisma/build/index.js generate
```

普通本机通常不需要。

### Q8. `next build` 失败？

先删除 `.next` 再构建：

```bash
rm -rf .next
npm run build
```

若仍失败，检查是否有旧 dev server 占用 `.next`，或换普通终端/ Docker。

## 二、量化与建议

### Q9. 为什么现金目标是 15%？

现金是政策缓冲，不是收益资产。风险平价会把低波动的货币 ETF 权重推得很高，所以系统把现金上限压到 15%，同时单独用应急金规划覆盖 3–6 个月支出。

### Q10. 为什么目标权重和我预期不一样？

目标权重经过三层处理：

1. 三套战略引擎集成；
2. 动量/趋势战术倾斜；
3. 约束投影（单只 ETF / 权益 / 海外 / 卫星 / 现金 / 换手）。

可以在「持仓与目标 → 约束条件」里调整上限，再重新分析。

### Q11. 回测能代表未来吗？

不能。回测使用历史数据、月度再平衡、单边 10bp 成本，未计冲击成本、税费与申赎限制；它只能说明规则在历史上的表现，不能保证未来。

### Q12. VaR 是什么意思？

VaR 是给定置信度下的估计损失分位数，不是最大损失保证。系统同时给历史法与参数法，并配合 CVaR、压力测试、最大回撤一起看。

### Q13. 为什么建议里没有具体股票？

产品定位是个人资产配置，不是证券投顾。个股推荐涉及适当性、牌照与合规风险；系统只给大类资产、策略权重、ETF/基金筛选与再平衡步骤。

### Q14. 数据不足会怎样？

历史不足的 ETF 从优化池剔除并在 warnings 标注；宏观缺失不补数字；约束不可行时投影器回退到可行权重；回测数据不足直接返回失败原因。

## 三、Agent 与多模态

### Q15. LLM 会不会编数字？

不会让它编。数字由量化引擎产出；LLM 只写叙事字段，不能修改 allocation/trades/risk。审查员检查个股推荐、目标价、收益承诺、权重合计与风险提示；越界会移除并降低置信度。

### Q16. 为什么有 8 个角色？是不是噱头？

每个角色对应一个明确的检查视角：规划、数据、宏观、组合、风险、目标、综合、审查。执行轨迹会显示每个角色看到了什么、输出了什么；没有 LLM 时同样有这些步骤，只是文字由规则生成。

### Q17. 图像输入怎么用？

在「智能决策 → 图像输入」上传 K 线截图、财报图片或持仓截图。需要配置视觉模型（`LLM_VISION_*`）；未配置时会明确提示，不会假装识别。

### Q18. 报告在哪里？

「研报与记录」可预览 HTML、下载 PDF；也可以直接访问 `/api/reports/{id}` 与 `/api/reports/{id}/pdf`。

## 四、答辩与演示

### Q19. 现场断网怎么办？

行情/宏观/报告有本地缓存；无 LLM 自动切规则智能体；演示前预热并准备 PDF/截图/录屏。

### Q20. 演示前要做什么？

```bash
npm run start:easy
# 设置 → 刷新真实行情与宏观
# 配置分析 → 运行一次
# 智能决策 → 运行一次
```

预开总览、持仓、配置分析、智能决策、研报五个标签页。详见 `docs/DEMO.md`。
